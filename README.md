# AASPAAS

**The Living Pulse of Every City**

Shipathon MVP — see [`docs/`](./docs/) for product requirements, architecture, and user journeys.

## Backend API

```bash
cd backend
npm install
npm run db:setup
npm run start:dev
```

Runs at `http://localhost:3001/api` — auth, users, cities, posts.

## Mobile app

```bash
cd mobile
npm start
```

Core flow:

Open app → Choose any city → City Pulse → Ask / Share (sign in) → Build Journey
