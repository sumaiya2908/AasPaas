# AASPAAS Mobile

Expo React Native app for the Shipathon MVP journey:

**Open app → Choose city → City Pulse → Place → Experiences → Ask → Build My Journey → Save**

## Stack

- Expo Router
- Zustand (+ AsyncStorage)
- Expo Linear Gradient
- Fraunces + DM Sans

## Run

```bash
cd mobile
npm start
```

Then press `i` (iOS), `a` (Android), or `w` (web).

## Demo flow

1. Continue as Guest
2. Pick Jaipur / Goa / Kochi / Hampi
3. Read City Pulse + Local Updates
4. Open a place → read Experiences
5. Ask a question
6. Build My Journey → generate → auto-save
7. Find it under the Saved tab
